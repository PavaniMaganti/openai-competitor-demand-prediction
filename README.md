# Competitor Demand Prediction Using Job Postings

**CadetX Individual Project**

## Project Overview

This project explores how job postings can be analysed using Natural Language Processing (NLP) and forecasting techniques to identify hiring trends, in-demand skills, and competitor demand in the AI and technology industry.

## Company Selected

OpenAI

## Project Objectives

- Analyse job postings and hiring trends.
- Identify frequently requested and emerging skills.
- Explore competitor hiring patterns.
- Develop demand forecasts using historical job-posting data.
